# 顶刊预备度判定表

逐项判断`pass / major-revision / blocked / not-applicable`，不计算总分。

| 维度 | 通过问题 |
|---|---|
| 期刊与读者 | 目标期刊文章类型、读者和当前作者指南是否明确？ |
| 领域价值 | 问题是否重要、及时且超出教材式总结？ |
| 原创贡献 | 是否形成可判定的新综合、理论修正、机制模型或方法洞见？ |
| 证据完整性 | 检索、家族、反证、证据槽和停止条件是否足以支撑结论？ |
| 推理可信度 | 每个核心主张是否有证据、桥梁、边界和替代解释？ |
| 结构可读性 | 题目、摘要、章节、段落和图表是否围绕同一中心贡献？ |
| 透明与规范 | 文章类型对应规范、局限、开放材料和声明是否完整？ |
| 审计闭合 | 来源对齐、数字/引用检查和独立模拟审稿阻断项是否关闭？ |

中心贡献、核心证据、来源对齐或期刊适配任一`blocked`时，不得用其他维度通过来抵消，也不得宣称可直接投稿。
