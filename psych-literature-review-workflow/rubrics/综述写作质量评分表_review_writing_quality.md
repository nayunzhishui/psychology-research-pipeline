# 综述写作质量判定表

本表不计算总分。任一阻断项不能被其他优点抵消。

| 维度 | 通过标准 | 阻断信号 |
|---|---|---|
| 类型与规范 | 综述类型明确，结构和报告规范匹配 | 叙述综述冒称系统综述，或规范混用 |
| 问题与贡献 | 问题精确，中心贡献相对既有综述可判定 | 只有宽泛主题、重要性口号或“文献很多” |
| 文献基础 | 检索、筛选、深读、研究家族和来源位置可追溯 | 先写后配引用、关键来源未读或二手替代原始证据 |
| 综合质量 | 按问题/理论张力综合支持、零、相反、混合证据 | 逐篇流水账、投票计数或隐藏异质性 |
| 科学推理 | 主张—证据—推理桥梁—边界完整 | 证据不能支持结论，或空白/未来方向凭空生成 |
| 理论建构 | 概念和箭头有状态、边界及可检验预测 | 把概念图当证据，或模型无法被证伪 |
| 段落与结构 | 每段任务单一，章节共同推进中心论证 | 引文堆砌、重复背景、段落无推进 |
| 透明度 | 方法、局限、利益冲突、AI/开放材料按期刊要求报告 | 关键选择或限制不可见 |
| 来源与语言 | 主张表、正文、引用、术语和禁止措辞一致 | 超过claim ceiling、引文错配或流畅但不可核验 |

只有全部核心维度通过、来源对齐完成且模拟审稿无未解决阻断项，才能标记“一区预备强度”；这不是发表保证。
