# 综述写作规范（中文心理学综述）

这份规范管中文综述的正文怎样写成目标期刊综述的样子，包括写作流程、结构、段落、反证与限定、文风、引用和投稿格式。相关文件各管一块：
- 证据能写到哪一步，由 `evidence-grounded-writing-contract.md` 管；
- 写完怎样检查，由 `review-prose-checklist.md`、`anti-defensive-writing.md` 和 `scripts/check_review_prose.py` 管；
- 图表由 `evidence-figure-contract.md` 管。

证据规则和本规范冲突时，证据规则优先。

## 0 三层规则

写作规则分三层：
1. **写的时候读**：本规范。只写“怎么写”，样例只放好的写法；
2. **写完才查**：`review-prose-checklist.md`（常见毛病、禁用的说法、改前改后的对照、文风参考数值）、`anti-defensive-writing.md`（防御式写法的完整目录）、`writing-before-after.md` 和 `check_review_prose.py`。写作时不读；
3. **底线**：写作合同里的证据规则，如不编造文献、页码、统计量和研究细节，保留禁止式。

这样分，是因为模型开发方和研究都发现：告诉模型做什么比告诉它不做什么有效（Anthropic 的提示文档：“Tell Claude what to do instead of what not to do”；DAIR.AI 提示工程指南）；被点名禁止的词反而更容易写出来（Rana, 2026；Jang 等, 2022）；同时给的规则越多，整体越难遵守（Jaroslawicz 等, 2025）；上下文里已有的写法会被照着模仿（Manus 的上下文工程经验；Xu 等, 2022 的自我强化效应）。规则自己的写法也会被模仿：满篇禁令的规范，会养出满篇“不能”“不等于”的正文。

**依据**：
- 《心理科学进展》2024—2026 年刊出的 40 篇综述（官网开放获取版），9 篇是系统综述或元分析，31 篇是叙述、理论和测量述评；做了逐篇统计，细读了其中 7 篇。
- 该刊的投稿指南、文献著录要求和综述论文自检报告。
- 一区期刊的 7 篇叙述综述（*Annual Review of Clinical Psychology* 5 篇、*World Psychiatry* 1 篇、*Development and Psychopathology* 1 篇，2005—2025 年，共 580 段），逐段统计，并逐段读了其中 3 篇的段首句和段末句。

**两类范例怎样分工**：投稿格式、引文著录、篇幅和文风照目标期刊；论证照一区期刊，包括论点先行、按评价标准组织证据、用例子展开关键研究。研究项数按检索方式定，作者自称的多少照目标期刊。投其他中文期刊时，结构和文风部分仍可参考，格式部分换成那本刊的要求。

## 1 写作流程：论证表在先，逐段写

1. **论证表。** 证据提纲的主张加上文章结构的小节，就是论证表。章和文章结构基本一致，小节按文章结构，段落可以和提纲不同。写一节前，在这一节草稿开头的注释里（如 Obsidian 的 `%% %%`）给每段写一行：
   - 作用：读完这段，读者应当相信什么；
   - 证据：用哪几项研究；
   - 落点：最后落到什么判断；
   - 已说过的：前文写过、这段直接用或指过去的内容。
2. **逐段写。** 一次写一段。动笔前依次读论证表里这一行、已经定稿的前文和第 8 节里同类段落的样例，最后读到的是这一段要做的事。
3. **每段写完就查**（`review-prose-checklist.md` 第 1 节和脚本），改好再写下一段。前文里留下的写法会被下一段照着写。
4. **每节写完**，把各段首句连起来读，应当就是这一节的论证；把各段末句列出来看，应当都是判断，或引向下一段的问题。
5. **请人读。** 作者或导师冷读后批注，按批注改。模型给自己的文字打分偏高，关键节点以人的批注为准。
6. **项目最好写一份自己的写作规范**，比如 `06_写作/写作规范.md`，同样分成写作时读的部分和写完查的检查清单，再加上项目特有的规定：题目、各章写法、术语账本、尚缺的材料。项目规范和本规范冲突时，以项目规范为准，证据规则照旧。

## 2 结构

### 2.1 五种结构

| 类型 | 骨架 |
|---|---|
| 概念—机制—模型型 | 引言 → 概念与测量 → 现象或特点 → 机制 → 影响因素或边界条件 → 整合模型 → 总结与展望 |
| 概念—影响—干预型 | 界定与分类 → 易感人群与影响 → 机制 → 干预 → 展望 |
| 测量与方法述评型 | 引言 → 概念辨析 → 测量方法 → 问题与局限 → 改进建议 → 展望 |
| 争议与理论比较型 | 背景 → 进展 → 争议 → 展望 |
| 系统综述和元分析型 | 引言 → 方法 → 结果 → 讨论 → 结论 |

- 系统综述和元分析设方法节。叙述综述把检索和证据评价写成引言里的一段，检索式、纳入标准和编码规则放附录。
- 前四类按问题组织：每个一级节回答一个问题，节题直接写出要回答的内容，写成判断或问题，如“X 是否只见于 Y？”。研究设计（横断、纵向、实验）在节内交代。
- 篇幅：正文约 1.1 万汉字（四分位 0.89 万—1.44 万），一级节 5 个（范围 3—7）。

### 2.2 题目

20 字以内，以科学问题作题，写出研究的问题本身。范例中位数 20 字，一半以上用冒号带副题。常见四种题型：主题加视角，如“X：基于 Y 的视角”；主题加本文模型；问句，如“X 如何影响 Y”；判断或意象。

### 2.3 摘要和关键词

- **字数**：投稿指南要求 200 字左右；范例刊出的约 290 字（265—342），5 句。
- **四步**：概念或意义 → 然而存在的问题 → 本文怎样梳理、提出了什么 → 未来研究。首句多为定义（“X 是指……”）或问题。
- **内容**：给核心概念下定义，每句写实质内容，写出本文的主要论点。
- **关键词**：3—5 个，用专业词汇。

### 2.4 引言

- **篇幅**：约 5 段、1,000 字，占正文一成左右。
- **四步**：现象和意义 → 近年进展 → 用“然而”指出问题 → 用“本文……”交代做法、要提出的框架和用处。“然而”引出的问题，多是概念不清、结论不一致、已有模型解释力不足，或缺少整合。
- **论点先行**：末段用一两句写出本文的论点，如“本文提出……”；结论回到同一个论点，说明证据支持到哪一步。一区综述 7 篇里有 6 篇在正文前 15% 写出论点或目的，5 篇在最后 10% 回到论点。
- **首句**：多用定义，或用现象和负担开头。
- **常见的补充**：专门交代国内研究；交代时效性，比如新版诊断体系何时生效。
- **两种可借的写法**：先讲研究对象的正常功能，再划清概念边界，然后指出已有研究的局限，最后提出本文的问题；或者把两种取向的定义并列，引出两者之间的张力。

### 2.5 主体

- **章首**：写这一部分要回答的问题和答案的方向。三分之二的一级节在第一个二级节之前先写这样一段。
- **先理论、后证据**：理论一节放在一部分的开头，节末一段写出这些理论推出的、后面各节要检验的推论。
- **理论段**：一种理论一段，写清它主张什么、推出什么、对本文的问题意味着什么。术语第一次出现就解释，例子要具体。几种理论放在一起时，另用一段说明它们的关系，比如“理论间的联系与区别”。
- **按评价标准组织证据**：要评价一个构念或主张是否成立时，先交代评价的标准，如效度准则、证据阶梯，再按标准逐项写。
- **证据综合**：按“共同发现 → 分歧 → 解释”组织，用研究的发现推进论证，而不是逐篇介绍。
- **小节之间**：每节第一句接住上一节的结论，说明为什么接着问这个问题。
- **不同观点**：放在它和本节论点直接相关的地方，写法见第 4 节。构念之间的区分放在讲概念的那一部分。
- **整合模型**：先用一句话写出整条通路；逐个节点或路径对上证据，标明证据状态（已支持、有条件、相反或混合、待检验）；说明模型成立的条件；配一张模型图；最后列出模型还要检验的具体问题。
- **节末和章末**：节末用最后一段的判断收束，需要时用一句引出下一节。一部分有章末小结时，小结以“综上”开头，逐个回答理论一节的推论，最后一句引出下一部分。

### 2.6 结尾

- **标题**：一级标题以“总结与展望”最多，其次是“结论”“展望”。约 1,700 字、11 段。
- **结构**：先用一段概括全文和本文模型，写明确的判断；再回应最可能的反对意见，如“有人可能认为……。本文不这样处理，因为……”；然后用动宾短语分 3—5 点写未来方向。
- **展望要能检验**：每点写成一项可以做的研究，说明检验什么、用什么设计、看到什么结果算支持或推翻。最好摆出两种对立的可能，再说明用什么设计能分辨。
- **本土化**：常单列一点，如中国文化背景、本土样本或本土工具。
- **局限**：写在结尾一章的一段里。每条局限写三件事：问题是什么，让结论往哪边偏、偏多少，什么研究能解决。

### 2.7 结论分档

各部分的结论按证据强弱，用自然语言分四档：已被支持；尚未确证，但是目前最好的推断；不被支持；尚无法判断。

### 2.8 图表

范例 30 篇有图，多为作者提出的模型或框架；20 篇有表，测量述评和元分析用得多。表格用三线表，至少三列，缩写在表注里定义。图表以外的内容写进正文。

## 3 段落和证据

- **一段一个任务**，长短随任务定。只下判断、做过渡或交代例外的段，可以只有一两句；汇总多项研究、并列几种设计的段，可以写到 250 字左右。同一节里长短错开。
- **段落骨架**：
  1. 判断（主题句）。证据段的首句写结论和证据强弱，强弱用设计、信息源和结果是否一致来说，如“……上，自评、访谈评定和临床组比较的结果方向相同”，分级用第 2.7 节的四档；
  2. 证据。一到三项研究，作者放在括号里，用“例如，”展开最能说明问题的一项，写它的设计和一个关键数字。优先展开设计最强、样本最大、或换了信息源的研究。其余研究按样本、设计或测法分组放进括号，成批的系数放进表或附表；
  3. 段尾。落在对论点的判断上，或引出下一段要回答的问题。

  不一致的结果只在论证表指定的位置写，写法见第 4 节。
- **判断标准在证据前面**：先说怎样才算数（如效标必须独立），再摆证据。
- **一个意思说一次**：同一判断全章只在论证它的那一段出现，别处用“见 3.x”指过去。章首提问题，理论一节的节末写推论，章末小结写答案；一节的首段直接进入第一个论证，末段落在最后一个具体判断上。
- **出处**：事实陈述标出处。作者自己的综合、评价和过渡不挂文献，范例中 42% 的段落不引文献；用证据提纲写作的项目，可以在注释里注上这些句子对应的主张编号。证据段引两三项代表研究，同类研究放进一个括号；判断、过渡和小结段不引。同时顾及全文参考文献的总数。
- **作者姓名放在括号里**。三种情况把作者写进句子：转述某人的理论主张、介绍某项研究的具体做法、对比不同研究。
- **数字**：效应大小用文字或区间表达，如“中等程度及以上的相关”；只在论证依赖效应大小的地方报一个数，并说明它的意思；成批的数字放进表。百分比多用于患病率、检出率这类描述性数字。
- **单项研究写多少**：写发现和影响结论的设计信息，比如“一项为期 6 天的生态瞬时评估研究发现……”。只有一项研究时写“一项研究发现”；多项一致时写明什么设计、什么样本；指代引到的研究写“这些研究”“上述两项研究”。系统综述和元分析照常报研究项数。
- **主张和证据分开**：理论主张用“认为”“提出”，实证结果用“发现”“表明”，证据和主张的关系用“支持”“提示”。
- **综述和元分析的引用**：见写作合同第 6 节“心理学综述”。

## 4 反证、限定和不同观点

- **反证用来补充解释、划定范围。** 全章只在论证表指定的几处写，每处三步：
  1. 不一致的结果是什么；
  2. 为什么会这样，原因优先从原文里找：样本、测量的范围、细分分数还是总分、单个领域还是整体、方向是否一致、有没有做差异检验；
  3. 对论点意味着什么：它解释了什么，或者结论适用到哪里。以见解收尾。

  能改变一项结论的设计问题（同源测量、结局是追溯式的、只有描述性比较），写在那项证据旁边，写一次，并说清它让结论往哪边偏。
- **不同观点**：先准确转述，可以引一句原话并注页码；再看对方的证据检验了什么；最后写本文的解释和理由。点名写，如“某某等人(年份)认为……”“其所引的……研究发现”。
- **按证据选词**，同一类证据全文用同一个词：

| 证据 | 写法 |
|---|---|
| 方法、测到的数字、公认的事实 | 直接陈述 |
| 转述别人的发现 | 照他们的设计说清他们发现了什么 |
| 横断相关 | 相关、伴随：睡眠越差的人焦虑越重 |
| 个体间的前瞻预测 | 预测、先于 |
| 个体内的滞后效应 | 比本人平常更重的时候，之后……也更高 |
| 横断数据里的中介 | 间接效应显著 |
| 随机对照试验或同等强度的设计 | 导致、改善、减少 |
| 多项研究一致 | 写明什么设计、什么样本 |
| 只有一项研究 | 一项研究发现 |
| 本文的推论或模型 | 本文提出、据此推测，写明依据哪几条证据 |

- **情态词**：从弱到强是“或许 < 可能 < 能够 < 应当 < 会 < 必然”，一句选一个。范例的限定几乎只靠“可能”（每万字约 18 次，40 篇都用）。
- **限定放在这些地方**：从相关推因果、推广到样本以外的人群、解释模糊的结果、讨论意义。描述方法、报告数字、陈述公认的事实、转述已发表的发现时直接陈述。
- **需要写的限定**，写具体：证据强度、适用范围、真正改变结论的局限、资料缺口、真实的更正、相反的证据和零结果、时效、安全和伦理提示。判断时问：这句是在帮读者用对结论吗？
- **作者的推论标明是作者的**：超出证据的推论用“本文认为”“本文推测”标出，每处标一次。“显著”“明显”“充分”“证实”用在证据确实到了那一步的地方。
- **研究建议写成具体的研究**（什么样本、什么设计、回答什么问题），放在结尾的展望里；局限放在结尾一章的局限段（第 2.6 节）。
- **改语气时守住主张**：改完对照原稿，主张既没有变强，也没有变弱。

## 5 文风

### 5.1 画像

这本刊的综述是客观、平实、书面化程度高但不艰涩的说明文：句子修饰完整，信息靠完整的句子组织，衔接写在明处，用词偏书面，交代研究的用处时写具体，作者在场但克制，修辞很少。

### 5.2 写法

- **句子写完整**：两到四个分句一句，主语、样本、测法和比较对象写完整。交代设计、结果和比较的句子可以长到六七十字，判断和过渡句可以短，一句可以交代清楚样本、测法和结果。
- **并列**：三项以上放进表，或写成“一是……；二是……”。
- **衔接**：逻辑关系用连接词写在明处，转折多用“然而”，递进用“同时”“进一步”“此外”，因果用“因此”“从而”，让步用“尽管”，举例用“例如”。段与段之间，用上一段的结论引出下一段的问题。
- **指代**用“其”。
- **术语**：核心术语第一次出现时括注英文；概念用中文说，工具才用缩写，缩写第一次出现时给全称。简短的例子放进括号“(如……)”。
- **从提纲和笔记改成正文**：补回主语、样本、测法和比较对象；条目写成完整的句子；标签句改成陈述句；段末或节末写这组证据说明了什么。

### 5.3 用词

- **报告动词**：实证结果用“发现”“表明”，理论观点用“认为”“提出”，证据和主张的关系用“支持”“提示”。
- **按意思选动词**：

| 要说的事 | 可以用的动词 |
|---|---|
| 研究做了什么 | 考察、探讨；“检验”留给有明确假设的研究 |
| 研究得出了什么 | 发现、表明；“揭示”用在证据够强的机制性结论上 |
| 本文做什么 | 梳理、整合、厘清、构建、提出 |
| 有什么用 | 为……提供、有助于、促进、深化、拓展 |

- **交代用处**写具体，比如“为区分 A 与 B 提供了跨信息源的证据”。“旨在”“以期”用于引言末段交代本文的目的。
- **骨架词组**（至少 12 篇用过），一节里换着用：
  - 报告研究：研究发现、研究表明、结果显示、有研究发现、一项研究、也有研究、多数研究；
  - 指称文献：已有研究、现有研究、以往研究、相关研究、实证研究；
  - 讲关系：之间的关系、存在差异、密切相关、呈正相关、相互作用、可能导致；
  - 衔接和界定：另一方面、具体而言、在此基础上、作为一种、被认为是、主要包括；
  - 展望：未来研究可以、进一步探讨。

### 5.4 修辞和语气

模型、通路和新概念起名加引号，全文统一；比喻少而具体，只用来解释机制；偶尔引一句有分量的原话点题，一篇一两处；以陈述为主；表态用“本文认为”“本研究提出”，“我们”也可以。

## 6 引文和参考文献（以《心理科学进展》为例）

照该刊的文献著录要求：采用著者−出版年制，基本依据 APA 第 7 版，中文另有细则。

**正文中的引用**：
- 可以作句子成分（“Dell (1986)提出……”），也可以放在句尾括号里（“(胡裕树, 1995; Dell, 1986)”）。
- 两位著者：句中写“张三和李四(2008)”；括号里写“(赵一, 陈二, 2008; Wolchik & West, 2007)”，中文之间用逗号。
- 三位及以上著者：句中写“张三等人(2008)”；括号里写“(赵一 等, 2008; Wolchik et al., 2007)”。
- 外国著者只写姓，中国著者写全名。同一文献连续引用时，第二次起可以只写著者。
- 中英文文献同在一个括号里时，中文在前。
- 转述对立的主张或关键定义时，可以直接引一句并注页码，一节一两处。

**文后的文献列表**：中文在前、英文在后；中文按汉语拼音排序，英文按姓氏字母排序。同一著者同一年的，在年份后加 a、b、c。元分析用到的文献前加星号。正文引用和文后列表一一对应，核对外国人的姓和名、页码范围符号和斜体。

**文献的新旧**：范例的参考文献中位数约 98 条，发表年前 5 年内的占 43%，前 10 年内的占 69%。自检报告要求说明是否以近 5 年为主；不是的话，说明理由。

## 7 投稿格式和自检（以《心理科学进展》为例）

- **标题层级**：写成 1、1.1、1.1.1，末尾一级后面直接接标题文字。
- **表格和插图**：表格用三线表；插图字号用六号。
- **字号**：中文摘要、关键词和正文用五号宋体；一级标题四号黑体，二、三级标题五号黑体；表格和参考文献小五号；数字和英文用 Times New Roman。
- **双盲**：作者信息只留在投稿系统里，文档属性、基金号和英文摘要里的作者与单位都清掉。
- **自检报告**：贴在稿件首页。第一作者是学生的，请导师单独给编辑部发邮件。另需稿件不涉密证明。

**综述论文自检报告**（共 14 条，没有第 4 条）和写作中的准备：

| 条目 | 要求 | 写作中怎样准备 |
|---|---|---|
| 1 | 一句话说出要解决的科学问题 | 写入引言末段；论证包里的“一句话问题” |
| 2 | 如何解决；总结和展望是否建立在前文论述上 | 模型和展望只用前文已论证的内容 |
| 3 | 创新贡献，正文相关文字标蓝，摘要里也要体现 | 标蓝的位置在动笔前就定好 |
| 5 | 中文期刊是否发表过类似综述 | 检索知网、万方、维普，列出相近综述 |
| 6 | 类似的外文综述，以及和本文的实质区别 | 从核心综述笔记的“借鉴与区别”汇总 |
| 7 | 参考文献是否以近 5 年为主（填列联表） | 证据相当时优先引近 5 年的研究，经典原文说明理由 |
| 8 | 引用观点是否注出处、有没有直译外文段落 | 借鉴注明出处，用自己的话综合，自检按剽窃认定直译 |
| 9 | 摘要是否有实质内容 | 按 2.3 节写 |
| 10 | 文中引用和文后列表是否一一对应，格式是否合规 | 按第 6 节核对 |
| 11—14 | 英文题目和摘要请人把关、删除作者信息、导师邮件、不涉密证明 | 投稿时办 |

## 8 样例和句式

只放好的写法。样例的研究内容是虚构的，只示范结构，作者和年份是占位符。写的时候看结构，不照抄句子。

**样例 1　证据段**

> 正念训练能降低焦虑，这一结论在不同设计和信息源上方向相同。随机对照试验发现，接受八周正念训练的成人，焦虑自评分的下降幅度大于等待组(作者, 年份; 作者, 年份)，换成临床访谈评定以后，干预组的改善仍然更大(作者, 年份)。例如，一项在门诊患者中进行的试验同时收集了自评和访谈评分，两种评分都显示干预组在随访三个月时焦虑更低(作者, 年份)。

首句给结论和强弱，再从自评到他评逐层加证据，用“例如”展开换了信息源的那一项。

**样例 2　反证段**

> 也有试验没有发现正念训练的效果，这些试验集中在在线自助的形式上(作者, 年份)。在线自助的完成率较低，没有完成大部分练习的参与者一并纳入了分析，效应因此被稀释；按完成练习的程度分组时，完成较多的参与者焦虑同样下降(作者, 年份)。可见，这类零结果反映的是练习量不足，它们也说明正念训练的效果依赖足够的练习。

不一致的结果、原因、对论点的含义，三步写完，最后落在论点和它的适用范围上。

**样例 3　补充范围的反证**

> 用正念的分维度解释不同的焦虑症状，还有一个测量前提：分维度在总分之外要有可靠的独特方差。用双因子模型检验时，总因子占主导，分维度的独特方差较小(作者, 年份)。这说明正念量表首先测的是一个总体水平；分维度之间的差别更适合用剖面来描述，而不宜当作彼此独立的分数分别解释。

**样例 4　理论段**

> 注意控制理论认为，焦虑的核心是注意向威胁信息偏移、个体难以把注意从担忧中收回(作者, 年份)。照此推论，能提高注意调控的训练应当先改变注意偏向，再降低焦虑。正念训练要求练习者反复把注意带回呼吸，本身就是一种注意调控练习，所以该理论预测，正念的效果部分通过注意偏向的改变实现。

**样例 5　节首承接**

> 上一节的试验说明，正念训练能降低焦虑。接下来的问题是这种效果怎样发生：如果注意控制理论成立，注意偏向的改变应当先于焦虑的下降。

**样例 6　章末小结**

> 综上，随机对照试验支持正念训练能降低焦虑，在线自助形式的零结果来自练习量不足；注意偏向的改变先于焦虑下降，这一推论得到了个体内追踪研究的初步支持。下一部分转向干预效果能维持多久。

**句式库**（从范例中抽出，X、Y 是占位符，只套框架）：

| 位置 | 用途 | 框架 |
|---|---|---|
| 引言 | 定义开头 | X 是指……（引用）。X 与……密切相关（引用）。 |
| 引言 | 现象开头 | X 是……的重要问题：……（数字，引用）。 |
| 引言 | 近年进展 | 近年来，研究者从……角度考察了 X 与 Y 的关系（引用），发现……。 |
| 引言 | 引出张力 | 然而，……对 X 的理解并不一致：A 取向认为……（引用），B 取向则认为……（引用）。 |
| 引言 | 本文 | 基于此，本文……。具体而言，首先……；其次……；最后……，以期为……提供……。 |
| 章首 | 提出问题 | X 能否……？现有证据来自……和……两类研究，它们一致指向……，分歧在于……。 |
| 理论 | 核心主张 | X 理论认为，……（引用）。据此，若……，则……。 |
| 证据 | 主题句 | ……与……正相关（引用 1；引用 2）。例如，某某等人（年份）发现……。 |
| 证据 | 分级的主题句 | ……上，自评、访谈评定和临床组比较的结果方向相同（引用）。 |
| 证据 | 更有说服力的设计 | 更能说明问题的是……的研究：……（引用）。 |
| 证据 | 反证 | 也有研究没有发现……（引用）。这一结果出在……上：……。可见，……（对论点的含义）。 |
| 立场 | 本文判断 | 本文认为，……。 |
| 过渡 | 用内容衔接 | 上述研究说明了……。接下来的问题是……（下一段直接回答）。 |
| 节首 | 承接 | 上一节说明了……。接下来的问题是……。 |
| 章末 | 小结 | 综上，……（逐个回答推论）。下一部分转向……。 |
| 结尾 | 回应反对意见 | 有人可能认为……。本文不这样处理，因为……。 |
| 结尾 | 概括 | 本文梳理了……，提出……。该模型认为……。 |
| 结尾 | 展望小标题 | 动宾短语：区分……与……；检验……的时间先后；开展……的本土研究。 |
| 结尾 | 可检验的展望 | 如果……，那么应观察到……；如果……，则……。未来研究可以通过……加以区分。 |
