# 综述正文写作分 skill

## 职责与入口

把已筛选、深读和按研究家族综合的心理学证据写成可追溯综述。开始前完整读取 `../../references/evidence-grounded-writing-contract.md`；涉及证据地图、理论模型、流程图、图注或视觉审计时同时读取`../../references/evidence-figure-contract.md`。输入为冻结协议、检索/筛选记录、阅读矩阵、证据账本、唯一主张表、质量评价、矛盾与空白登记及综合备忘录；逐篇阅读总结只作辅助视图。

## 综述类型路由

先声明叙述、理论、整合、范围、系统或元分析类型。系统综述/元分析使用PRISMA 2020及适用扩展；范围综述使用PRISMA-ScR；无元分析的系统综合按需使用SWiM；叙述/理论综述以检索透明度、科学推理和证据呈现为核心，可参考SANRA自审但不以总分替代判断。

## 执行

1. 冻结一句话问题、中心贡献、目标读者、3–6条核心主张、反证和figure contract；每条主张绑定`claim_id`及研究家族，流程图和证据图数字必须能回到正式记录。
2. 以问题、理论张力或证据槽搭建章节，不按作者/年份逐篇罗列。先写综述范围/方法与证据综合主体，再写引言、整合模型、讨论/未来方向，最后反写题目和摘要。
3. 段落使用“主张—跨研究证据—推理桥梁—异质性/反证—推进”；区分原始证据、二手解释和本综述的新推断。
4. 每个综合单元同时呈现支持、零、相反、混合结果和设计/测量/人群边界；同一研究家族不重复计为独立证据。
5. 整合模型的概念或箭头标记为已支持、条件性、相反/混合或待检验；未来研究建议必须由已登记缺口触发并说明可检验设计。
6. 叙述综述也要说明范围、检索、来源选择和局限；不得冒称systematic、PRISMA-compliant或穷尽性证据。
7. 完成反向提纲，以及贡献结构、证据来源、推断反证、语言可读性、图件最终尺寸和期刊规范五轮修订，再交来源对齐和模拟审稿。

## 输出与停止条件

优先原位更新`综述框架_review_outline.md`、章节主张表、图表计划、`综述正文_manuscript.md/.docx`和APA参考文献。缺少协议、阅读矩阵、证据账本或唯一主张表，不得生成投稿级正文；关键证据槽不足时回到检索/深读。不得伪造文献、页码、理论贡献、研究空白或综述类型。
