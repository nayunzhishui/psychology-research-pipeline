# 顶刊预备度判定表

逐项判断`pass / major-revision / blocked / not-applicable`，不计算总分。

| 维度 | 通过问题 |
|---|---|
| 期刊与读者 | 目标期刊、综述类型、读者和当期规范是否明确？ |
| 机制贡献 | 是否提出可证伪且相对既有综述新增的机制框架？ |
| 证据层级 | 行为、主观、神经和生理证据是否分层并正确综合？ |
| 模态与方法 | 采集、预处理、排除、ROI/全脑、校正、灵活性和泄漏是否可评价？ |
| 推断边界 | 是否控制反向推断、跨模态尺度错配和因果夸大？ |
| 矛盾证据 | 零、相反、混合结果及异质性来源是否进入主论证？ |
| 图表与结构 | 机制图、方法表、题目、摘要和正文是否共享同一证据故事？ |
| 可追溯性 | 主张、研究家族、PDF/表图位置、Reviewer和来源对齐是否闭合？ |
| 审稿闭合 | 理论、范式、模态方法、统计、开放科学和主编风险是否处理？ |

机制贡献、关键模态方法、推断边界、来源对齐或期刊适配任一`blocked`时，不得用其他维度通过来抵消，也不得宣称可直接投稿。
