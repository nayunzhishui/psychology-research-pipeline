# 认知神经科学综述正文写作分 skill

## 职责与入口

把已核验的行为、主观、神经/生理和方法证据写成机制、理论、方法、范式或指标综述。开始前完整读取 `../../references/evidence-grounded-writing-contract.md`；涉及脑图、波形、时频图、机制图、图注或视觉审计时同时读取`../../references/evidence-figure-contract.md`。输入必须包含冻结协议、阅读矩阵、证据账本、机制矩阵、方法/预处理评价、证据提纲（按章、节、段列出机制主张与证据）和矛盾登记；阅读笔记提供逐篇细节。起草时逐段对照证据提纲写，提纲里的“可以写成”和“不能写成”是措辞上限。

## 认知神经覆盖层

1. 先声明综述类型和模态范围，选用相应综述规范，并按材料叠加COBIDAS MRI、COBIDAS MEEG或其他经核验的模态/期刊清单。
2. 冻结一句话机制问题、中心贡献、目标读者、机制主张阶梯和图表计划；按机制问题组织，不写成脑区、ERP成分或模态目录。
3. 机制主张依次区分观察、关联、时间/实验支持、机制候选和因果效应。每条主张绑定`claim_id`、研究家族、模态、结果层级、证据位置和`claim_ceiling`。
4. 分别综合行为、主观、神经和生理证据，再判断收敛、分歧及空间/时间/测量尺度不可互换处。反向推断不能成为唯一推理桥梁。
5. 主体按“问题—跨研究证据—方法可比性—机制解释—替代解释—边界”推进；显式处理采集、预处理、伪迹/排除、ROI/全脑、时间窗/频带、多重比较、分析灵活性、交叉验证/泄漏和开放材料。
6. 按figure contract冻结每张图的问题、证据层级、来源、分析单位、模态参数、颜色尺度、图注和导出；机制图使用实线、虚线、冲突/未知标记区分证据强度，方法比较表解释异质性来源，示意脑区不得冒充定位结果。
7. 题目、摘要和结论不得把神经关联写成确定机制或因果；完成反向提纲，以及贡献结构、证据与模态、推断反证、语言可读性、图件最终尺寸和期刊规范五轮修订。

## 输出与停止条件

优先原位更新综述框架、章节主张表、图表计划、`综述正文_manuscript.md/.docx`和APA参考文献。没有阅读矩阵、机制矩阵、方法评价或唯一主张表时，不得生成投稿级正文；关键机制证据缺失、跨模态尺度不匹配或主张超上限时回到深读/综合。不得伪造文献、页码、脑区/成分结果、范式、模态参数或理论贡献。
