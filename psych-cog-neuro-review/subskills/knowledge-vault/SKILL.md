# 知识库（Obsidian）

知识库边读边建：
- 第一次精读前，库还不存在，先初始化；
- 之后每精读一篇，这篇涉及的概念、工具、结局、方法和样本就新建或补进知识库，节点卡写成给新手的讲义，资料联网查；
- 每批跑一次激活扩散。

不预先批量建节点。

## 什么时候用

- 第一次精读前，项目还没有知识库；
- 读完三轮、动笔写阅读笔记之前（补课）；
- 每写完一篇阅读笔记（精读的“连知识库”一步就是按这里做）；
- 每批阅读结束后，更新激活扩散；
- 用户要按概念找文献，或想看知识网络。

## 开始前读

`../../references/knowledge-vault-contract.md`。同一会话里已经读过的，不用重复读。

## 第一次建库

只在库还不存在时做一次。

1. **定三件事**，按合同第 1 节：
   - 根目录：这个主题最上层的文件夹，要把项目文件和全文 PDF 都包在里面。拿不准时问用户一次，答案写进项目的 AGENTS.md。
   - 主题名：取项目方案里的主题，用简短的中文名，如“人格功能”。
   - 要排除的文件夹：旧项目、tmp、原始导出、旧笔记。全文 PDF 所在的文件夹不能排除。
2. **运行初始化**：
   ```text
   python <skill>/scripts/init_knowledge_vault.py --根目录 <根目录> --主题 <主题> --排除 <文件夹/> --排除 <文件夹/>
   ```
   实证论文项目再加 `--结局目录 变量`。已有的文件不会被覆盖。
3. **不建种子节点。** 节点在读到时再建；用户另外要求时，才从方案里批量建。
4. **在交接里写一句**：库建在哪里，怎么打开。打开方法是在 Obsidian 里选“打开本地仓库”，选根目录，从 `<主题>知识库/首页.md` 开始看。

## 动笔前补课

读完三轮、动笔写笔记之前做，对应七步里的第 1–3 步：
1. **列节点**：这篇用到的构念和术语、测量工具、结局（或变量）、方法和模型、样本或队列。
2. **查重**：中文名、英文名、缩写各搜一遍。
3. **新建或补讲义**：库里没有的建卡；已有但讲义不够的（只有一两段，或只写了某一篇怎么用），补成讲义。
   - 先定档：核心节点写完整讲义；只在一两篇文献出现的外围节点写 300–500 字的简短讲义，被第 3 篇笔记用到时再升级（合同 3.2）。
   - 完整讲义讲什么，按节点类型看合同 3.2 的清单：测量工具要有维度表、题目、计分和分数解释；方法要有模型结构、参数含义和一个读数的例子；样本要有样本概况表。
   - 资料按合同 3.5 联网查：有 `web-access` skill 的用它；先查原始开发论文、正式题本、手册和方法奠基论文；每个事实句末标资料编号，卡末“资料来源”列全。
   - 题目：免费公开的工具全部列出，原文加中文；商业版权的逐题概述，再加 1–2 道已公开发表的原题。
4. **放补课框**：写笔记时，每个关键节点第一次出现的那一节放补课框，把讲义嵌进来，写法见 `reading-note-style.md` 第 9.1 节。

## 每写完一篇笔记

按合同 3.4 的七步做（第 1–3 步动笔前已经做了的，这里只补漏）：
- 4 级文献做全部七步；
- 3 级文献做第 1、2、3、6、7 步，第 4、5 步只对主要发现做。

七步是：
1. **列节点**：构念和术语、测量工具、结局（或变量）、方法和模型、样本或队列。
2. **查重**：中文名、英文名、缩写各搜一遍。
3. **新建或补讲义**：按上面“动笔前补课”做；再写一句话、一条关联，以及这篇的一行证据。
4. **补关联**：这篇检验过的关系，加一行或调整强度，依据链接到笔记里的发现块。
5. **写证据**：在这篇真正说明了什么的节点卡里，“证据与争议”加一行。
6. **连回笔记**：属性写成双链列表，正文中第一次出现时加双链。
7. **记一笔**：在笔记的“提取记录”里写明新建了哪些节点、补了哪些关联、在哪些卡里写了证据。

建卡时：
- 文件名用中文名；测量工具和模型可以用通用缩写，如“LPFS-BF 2.0”“RI-CLPM”。
- 别名里写英文全称和缩写。

## 每批结束后

每读完一批（约 10 篇）或每周运行一次，不用每篇都跑：

```text
python <skill>/scripts/spreading_activation.py --知识库 <主题>知识库
```

## 不能做的

- 不建同义节点。
- 不把文献建成概念节点。
- 两个节点只是在同一篇里都出现、没有检验它们之间关系的，不手写关联，交给脚本按共现计入。
- 关联强度要有依据：“强”只用于定义上的关系，或 3 项以上独立研究结果一致。
- 激活值只用来联想和找文献，不写进论文当证据。
- 讲义不能只写某一篇怎么用，也不能只写一句“未核对原文”；查不到的资料，在“资料来源”里写清查过哪里。
- 外查资料只进讲义，不当证据挂进证据提纲。
