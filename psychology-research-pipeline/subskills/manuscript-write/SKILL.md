# Empirical Manuscript Write / 实证论文写作分 skill

## 职责与入口

把已冻结的研究问题、方法、已验证统计结果和已复核文献主张写成APA兼容实证稿。开始前完整读取 `../../references/evidence-grounded-writing-contract.md`；涉及表图规划、图注或视觉审计时同时读取`../../references/evidence-figure-contract.md`。报告规范由 `../reporting-standards/` 选择，来源、数字和图件由后续对齐阶段复核。

正式起草必须具备研究问题/估计对象、方法冻结稿、已验证结果、阅读矩阵、证据账本、唯一主张表和目标文章类型。逐篇阅读总结只是派生视图。材料不全时只能生成带`AUTHOR_INPUT_NEEDED`或`EVIDENCE_BLOCKED`的结构稿。

## 实证覆盖层

1. 按横断/纵向观察、实验、干预、测量、质性或混合方法选择APA JARS模块及适用补充规范，不以清单替代设计质量判断。
2. 先按figure contract冻结表图问题、`claim_id`、来源输出、分析单位、估计量/不确定性、图注和导出计划，再形成论证包；优先写方法、结果，随后写引言、讨论、结论，最后反写题目和摘要。
3. 引言必须明确构念、估计对象、时间结构、精确缺口、当前研究贡献和可判定假设；不以“鲜有研究”代替缺口。
4. 方法写到可判断重复性、偏倚和适用性的程度，报告样本流、测量、计分、缺失、聚类、协变量、模型、伦理、预注册和开放材料状态。
5. 结果按研究问题组织，逐项报告主要、次要、探索性、零、相反和混合结果，以及效应量、不确定性、精确样本量、拟合/诊断和稳健性。正文不复制整张表。
6. 讨论首段直接回答研究问题，随后区分结果事实、解释、替代解释、理论意义、局限和外推；严格区分个体间/个体内、关联/时间预测/因果以及组内显著/直接组差。
7. 每段落实“主张—证据—推理桥梁—边界/反证—推进”；理论、事实和解释主张绑定`claim_id`，结果主张绑定已验证输出。
8. 完成反向提纲，以及贡献结构、证据数字、推断反证、语言可读性、图件最终尺寸和期刊规范五轮修订，再交来源对齐和模拟投稿审稿。

## 输出与停止条件

优先原位更新现有`论文正文_manuscript.md/.docx`、APA参考文献和唯一主张表。关键结果未验证、正文数字与输出不一致、核心主张未达`agreed/adjudicated`、文章类型/报告规范或目标期刊未核验时，不得标记投稿预备完成。不得补造文献、页码、统计结果、DOI、伦理或开放科学声明。
