# 受控科研系统架构

## 五层结构

1. **科研业务流程层**：十二阶段是唯一状态机；gate 决定能否前进。
2. **受控执行层**：六个研究角色只执行任务契约中的动作，不得跨阶段或扩大权限。
3. **Skills 与工具层**：Skill 解释方法和产物；工具只提供被登记的能力。
4. **证据资源层**：不可变原始来源、结构化证据账本、可重建检索索引分开保存。
5. **审计层**：输入、代码、环境、输出均记录 SHA-256、版本、决策、失败和批准。

主流程始终是：十二阶段状态机 → 受控角色 → Skill/工具 → 证据与产物 → 哈希和人工门禁。

## 人工批准点

- 研究问题、主要估计对象和推论边界；
- 检索协议、纳排标准与 Zotero 精确集合；
- 量表来源、计分、异常数据和缺失数据裁决；
- 主模型、敏感性分析和探索性重分类；
- 伦理、开放科学声明、目标期刊和最终投稿包。

自动化不得把 `prepared`、`generated`、`indexed` 或 `simulated` 改写为已执行、已核验或已投稿。

## 敏感数据边界

青少年行级数据、姓名/学号、学校/班级标识、行级自伤信息和可重识别组合不得进入浏览器、Zotero、RAG、向量数据库或通用 Agent 上下文。Rscript 仅在本机受控分析目录读取冻结后的最低必要数据。
