# 一区预备强度的证据约束写作合同

本合同用于三套工作流的正式正文写作、章节重写和投稿前结构审计。它提高“一区预备”的论证与审查强度，但不承诺期刊分区、送审、接收或发表。目标期刊、文章类型和当期作者指南仍须在执行时核验。

## 1. 写作入口

正式起草前必须具备：

1. 冻结的研究/综述问题、构念边界、文章类型、目标读者与中心贡献；
2. 已核验的结果或跨研究综合，以及阅读矩阵、证据账本和唯一主张表；
3. 适用报告规范与目标期刊要求；
4. 关键主张的`claim_ceiling`、反例/零结果和Reviewer状态；
5. 对缺失材料、未决分析和不可写主张的显式清单；
6. 已按`references/evidence-figure-contract.md`冻结核心图件问题、来源输出、分析单位、估计量、图注和导出计划。

缺一项时可以写结构草案或占位符，但不得标记为投稿级正文。`AUTHOR_INPUT_NEEDED`和`EVIDENCE_BLOCKED`必须保留，不能用流畅措辞掩盖。

## 2. 写作前论证包

先形成一个可复核的论证包，不先写成篇正文：

- 一句话研究/综述问题；
- 一句话中心贡献，以及它相对既有文献新增了什么；
- 目标读者为何需要知道；
- 3–6条核心主张及对应`claim_id`、结果输出或研究家族；
- 每条主张的证据、推理桥梁、反证/替代解释、表述上限和落点段落；
- 每条关键解释中的作者主张、结果事实和本稿推断必须分开；
- 题目、摘要、正文、表图应共享的主结果与禁止措辞；
- 图表计划：每个显示项回答什么问题，支持哪条主张，数据/输出从哪里来，分析单位和不确定性是什么，正文不得重复抄表。
- 术语与数字账本：核心构念、缩写、组名、时间点、估计量、效应方向、小数精度和缺失/零值用语在全文只采用一套定义；变更时同步题目、摘要、正文、表图与补充材料。

每个论证段落只承担一个主要任务，基本单元为：**主张 → 证据综合 → 推理桥梁 → 边界/反证 → 向下一段推进**。不是每段都机械写五句，但不能只有引文堆叠或无证据判断。

同时建立读者路径：标题和摘要给出问题—发现—边界；引言形成旧知识→未解决张力→本稿动作；结果与核心图按问题而非执行顺序推进；每段开头承接已知或问题，句末放置本句要推进的新信息。完成章节后做反向提纲：只读每段第一句、最后一句及图题，若无法复述完整论证，先重构结构再润色。引用密度由主张复杂度决定，不设置“每段几篇”的配额；优先原始理论、原始测量、原始研究和正式规范，综述性来源不能替代其未直接验证的强主张。

## 3. 起草顺序

优先按证据确定性而非论文显示顺序起草：

1. 冻结表图、结果/证据综合和方法事实；对每张核心图先写一句结论和证据边界；
2. 写方法与结果，或综述的范围/方法与证据综合主体；
3. 写引言与讨论/整合模型；
4. 写结论；
5. 最后写题目和摘要，并与正文、数字和主张上限反核。

语言润色不得早于事实、结构和主张对齐。不要用“先写后找文献”或为了故事顺畅隐藏零结果、相反证据和方法失败。

## 4. 章节合同

### 题目

标明真实对象、设计或综述范围和核心关系；不使用设计不能支持的因果或机制词。题目承诺必须能在摘要和正文中找到对应证据。

### 摘要

交代问题/目的、设计或证据范围、关键方法、最重要的量化或综合结果、结论与边界。除非期刊要求，不以背景或口号占据主要篇幅。摘要中的样本量、方向、效应、时间范围和结论必须与正文一致。

### 引言

按“重要问题 → 已知及证据边界 → 精确缺口 → 当前研究/综述如何解决 → 可判定问题/假设与贡献”推进。缺口不是“无人研究”，而是现有证据在构念、估计对象、设计、机制、样本或综合上的具体不足。只引用实际支撑句子功能的来源。

### 方法或综述方法

让读者能够判断可重复性、偏倚和适用性。实证稿报告样本、设计、测量、程序、数据处理、分析、伦理和开放科学；综述稿报告类型、范围、检索、筛选、提取、家族处理、质量评价和综合方法。报告规范未覆盖的设计关键点仍须说明。

### 结果或证据综合

按研究问题和预定比较组织，而非按分析执行时间或逐篇罗列。报告支持、零、相反、混合结果及不确定性；表图和正文分工。不得在结果中偷换主要/探索性地位，也不得把多个同一研究报告计作独立重复。

### 讨论或整合

首段直接回答研究问题。随后分开写：结果事实、作者解释、与既有证据关系、替代解释、方法与外推边界、理论/实践意义和可检验的后续问题。新引入的文献主张仍须入表；不能以“机制”“中介”“预测”等词绕过设计上限。

### 结论

只收束已建立的贡献、最稳健发现和边界，不引入新证据，不重复摘要，不用宏大口号替代可判定结论。

### 表图、补充材料与声明

每个表图必须有独立问题、清楚的分析单位、样本量、统计量/不确定性、自足图注和可追溯source data/输出。主文保留读者理解中心结论所需的最短充分证据链；稳健性细节和扩展分析可进入补充材料，但关键方法、主要失败或会改变结论的结果不得隐藏。图1优先承担“研究设计/证据结构＋最重要发现”中的核心读者任务，但不为形式强制生成。完整图件门槛见`references/evidence-figure-contract.md`。数据、代码、材料、预注册、伦理、利益冲突、资助、作者贡献和AI使用按目标期刊规则披露。

## 5. 文章类型路由

- **心理学实证稿**：以APA JARS对应模块为主；观察性、随机试验、质性/混合、测量或其他设计再叠加相应规范。报告规范不等于质量通过。
- **系统综述/元分析**：使用PRISMA 2020及适用扩展；无元分析的结构化综合按需要使用SWiM。
- **范围综述**：使用PRISMA-ScR，不把范围绘制写成效应确定性结论。
- **叙述/理论/整合综述**：明确范围、检索透明度、来源选择与科学推理；可以用SANRA作自审参考，但不把总分当作发表判断。
- **认知神经科学稿**：在上述文章类型上叠加适用模态规范，如COBIDAS MRI/MEEG及目标期刊报告清单。

若多个规范适用，先按文章类型选主规范，再补设计/模态模块；不得把PRISMA、STROBE、CONSORT或COBIDAS当作可互换标签。

## 6. 三套领域覆盖层

### 实证心理学

- 引言明确构念、估计对象、时间结构和理论上可证伪的预测。
- 方法与结果区分主要、次要、探索性及偏离；报告效应量、不确定性、精确样本量、模型诊断和全部目标结果。
- 讨论区分个体间/个体内、关联/时间预测/因果，不以“一组显著另一组不显著”声称组差。
- 题目、摘要、正文、表图和代码输出进行数字与措辞双重对齐。

### 心理学综述

- 先声明叙述、理论、整合、范围、系统或元分析类型；结构和规范随类型变化。
- 正文按问题、理论张力或证据槽综合，不按作者或年份流水账排列。
- 区分原始证据、二手解释和本综述的新整合；同一研究家族只贡献一次独立证据计数。
- 整合模型中的每条箭头标记为已支持、条件性、相反/混合或待检验；未来研究建议必须由明确缺口触发。

### 认知神经科学综述

- 按机制问题组织，不写成脑区、ERP成分或模态目录。
- 机制措辞分为观察、关联、时间/实验证据、机制候选和因果效应；反向推断不能承担唯一桥梁。
- 行为、主观、神经与生理证据分别报告，再判断收敛、分歧及空间/时间/测量尺度不可互换处。
- 机制图使用实线/虚线/冲突标记区分证据强度；图注列出关键边界和来源。
- 写作时复核采集、预处理、伪迹/排除、ROI/全脑、时间窗/频带、多重比较、分析灵活性、交叉验证/泄漏和开放材料。

## 7. 五轮修订与停止条件

1. **贡献与结构**：中心问题、贡献、段落任务、图表故事和反向提纲能否成立；删去段落后若不改变论证或证据边界，应合并或删除。
2. **证据与数字**：每条主张是否有正确来源/输出，研究家族、零结果、数字和位置是否一致。
3. **推断与反证**：claim ceiling、替代解释、边界、异质性和不支持项是否如实呈现。
4. **语言与可读性**：术语与数字账本一致、段落衔接、信息密度、英文表达和作者声音；逐项清理空泛评价词、名词堆叠、无指代的`this/these`、过长主语与把限制藏在句尾的写法，不以套话模拟“Nature风格”。
5. **期刊与最终审计**：当期作者指南、文章类型、报告清单、摘要/题目、参考文献、表图、图注、最终版面可读性、声明和模拟审稿问题闭合。

关键主张无证据、结果与正文不一致、主要材料缺失、Reviewer冲突未裁决、报告规范或目标期刊未核验时，保持`blocked/major revision`。一区预备度采用逐项判断，不计算总分，也不用其他优点抵消关键失败。
