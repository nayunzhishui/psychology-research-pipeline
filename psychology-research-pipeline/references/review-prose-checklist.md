# 综述正文检查清单（中文心理学综述）

这是写作规则的第二层：每段写完、每节写完时读，写作时不读。这里点名列出常见的毛病和禁用的说法，写作时读到它们，反而容易写进去（依据见 `review-writing-standard.md` 第 0 节）。怎么写，看 `review-writing-standard.md`；防御式写法的完整目录见 `anti-defensive-writing.md`；笔记改写前后的对照见 `writing-before-after.md`。

## 1 每段写完查

1. **段尾**：最后一句是判断、解释，或引出下一段的问题吗？如果是限制、保留或“还需要……”，删掉，或者改成见解。
2. **重复**：有没有一句在用另一种句式，重复前文已有的论证？在全章范围里找。
3. **离题**：这段对本节论点有什么用？构念之间的区分、定义、测量范围是不是属于讲概念或测量的那一部分？
4. **反证**：如果这段是反证，它在论证表指定的位置吗？写了原因和对论点的含义吗？
5. **标准**：判断标准在段首吗？
6. **证据**：事实句有出处吗？措辞超过证据了吗？非系统检索的叙述综述有没有报研究项数、用穷尽说法？同一类证据是不是全文用同一个词？
7. **读得懂**：第一次出现的术语解释了吗？信息是不是密到读者要回头重读？
8. **证据本身**：关键研究测到这个构念了吗？是不是同源测量？结局是不是追溯式的？这些问题决定措辞写到哪一步，写进正文时只在那项证据旁边写一次。
9. **脚本**：运行 `python scripts/check_review_prose.py <草稿.md>`，处理“硬错误”一栏。

## 2 每节写完查

1. **首句连读**：把各段首句连起来（脚本的“骨架”一栏），能读出这一节的论证吗？
2. **末句列表**：各段末句都是判断，或引向下一段的问题吗？
3. **承接**：这一节的第一句接住上一节的结论了吗？
4. **只说一次**：同一判断在全章只出现在论证它的那一段吗？节内有没有开头预告、节末有没有“总之”式的复述？
5. **局限的位置**：共同的局限在结尾一章的局限段，研究建议在展望里；正文里只有能改变一项结论的设计问题，写在那项证据旁边，且只写一次。

## 3 常见毛病和禁用的说法

脚本会查第 1—4 类，其余靠读。

1. **段尾防御**：段尾写“但……没有……”“然而……还需要……的研究来回答”“这要靠纵向证据分辨”“只能看作待检验的假设”“还不能把……分开”“还不能下结论”“有待专门研究”“需要用……复核”“但只是描述性比较”“本节……需要……复核”。研究建议写进展望一节是对的，脚本在那里的提示可以忽略。
2. **研究项数和穷尽说法**（非系统检索的叙述综述）：“至少 9 项研究”“只有 3 项研究”“本文只找到 2 项”“尚无……的研究”“研究还很少”“唯一的研究”“证据最多”“无论哪一类”。审稿人只要找到一篇漏掉的研究，整句就站不住。系统综述和元分析报项数是对的，脚本加 `--systematic` 跳过。
3. **标签**：“反方”“反对者”。点名写成“某某等人(年份)认为……”。
4. **空过渡和目录句**（`anti-defensive-writing.md` 第 19、20 条）：“值得注意的是”“需要指出的是”“综上所述”“总的来说”“具有一定的”“具有重要意义”“有待进一步研究”“笔者”；“本节将”“本部分将”“下文将”“如前所述”。“综上”只用在章末小结；“首先……最后”只在真有先后顺序或三点并列时用。
5. **防御写法**（`anti-defensive-writing.md` 第 3 节的编号）：1 处处认错；2 限定词堆叠；4 空提醒；7 把限定写进标题；8 先铺局限、后给结论；9 把零结果写成失败；13 借权威；16 列出所有可能却不选一个；22 把每条批评变成一句限定；25 没有停止条件。
6. **反证的写法**：只列出不一致的结果、不写原因；写了原因却没有落到对论点的含义；反证分散在每一段；为了显得周全，在每项关键发现后都补一句替代解释和“什么设计能分辨”。
7. **假对比**：“不仅……而且”“并非……而是”只在前后两半都提供信息，或纠正一个真实存在的误解时用。
8. **文风**：
   - 电报体，如“多为同一次自评”“均未显著”；
   - 分号串条目；“X：Y”式的标签句；
   - 口语词：其实、所以、就是、这个、那么、比如；
   - “均”“皆”“亦”用得多；“证明”；
   - 段落以研究者姓名开头；
   - 一句里叠用两个情态词；“或许发现”；
   - 横断数据写成“导致”“通过……导致”；
   - 同一个骨架词组在一节里反复用；
   - 每段都写到同一个长度、同样几句。
9. **格式**：题目里出现“研究综述”“进展”“回顾与展望”“述评”；摘要写“指出了以往研究的不足，对未来研究进行了展望”这类空话；摘要里放参考文献；末尾一级标题后加小圆点；用文本框；表格加竖线。

## 4 改前改后

下面的例句是通用的示范，不对应真实研究。

| 毛病 | 改前 | 改后 |
|---|---|---|
| 段尾防御 | “因此，这一前提得到确认以前，依据分维度的结果只能看作待检验的假设。” | “总因子占主导，说明量表首先测的是一个总体水平；分维度之间的差别更适合用剖面来描述。” |
| 反证不给原因 | “也有试验没有发现效果。两类干预形式的效果是否不同，还需要在同一样本中比较。” | “也有试验没有发现效果，这些试验集中在在线自助的形式上。……可见，这类零结果反映的是练习量不足。” |
| 反证段只剩防御 | “然而，这些研究只并列了两组系数，没有检验差异，换成他评以后系数缩小多少，还需要检验相关之差的研究来回答。” | “换成访谈或另一方的报告以后，相关大多降低，但多数仍为中等，说明正相关并不只是同一信息源造成的。” |
| 标准放在段尾 | “回答这一问题，需要以内容独立的指标为效标……”（段尾） | 挪到段首：“判断 A 能否与 B 区分，要看控制 B 以后，A 对内容独立的指标是否仍有增量。” |
| 换句式重复 | 一节里先后写“只说明相容”“很难分开”“回答不了”“要打折扣看”“还不能下结论” | 这层意思只在章末小结写一次 |
| 固定的防御句 | “本节的增量大多来自观测分的回归，需要用潜变量模型复核。” | 删去；方法建议写进展望 |
| 研究不足放在段尾 | “……与 A 的关系，还有待专门研究。” | 段首直接写：“……与 A 关系的研究相对不足，现有结果多由同时测量多种结局的研究附带报告。” |
| 为反驳而写 | “因此，横断数据分不清是 A 加重了 B，还是 B 使 A 暂时变差，这要靠纵向证据分辨。” | 删去；理论观点改作正面解释，说明 A 与 B 为什么共变 |

**提纲体改成正文**：

> 改前：A 与 B 总分多为中到高的正相关（样本 1 r = .71，样本 2 .76）；诊断数量的关联较弱（.28，另一研究未显著）；剖面中段不单调。
>
> 改后：A 与 B 的总体严重程度呈正相关。在青少年和成人、社区和临床样本中，A 越……，个体报告的总体困扰越高，二者多呈中到高度相关(作者, 年份; 作者, 年份)。然而，当结局换成临床访谈确定的诊断数目时，这一关联明显减弱(作者, 年份)。由此可见，A 与 B 总水平的关联，强于其与诊断数量的关联。

改法：第一句先给判断；分号串起来的条目改成完整的句子；用连接词衔接；数字换成文字描述，工具缩写不进正文；作者放进括号；最后一句说明这组证据说明到哪一步。

**从提纲和笔记改成正文时最常见的问题**：

| 问题 | 改法 |
|---|---|
| 句子短，压缩成名词堆，比如“多为同一次自评”“均未显著” | 补回主语、样本、测法和比较对象 |
| 分号串起一串条目 | 写成完整的句子 |
| 冒号式的标签句 | 改成陈述句 |
| “均”“及”用得多 | 照范例的量用 |
| 动词集中在“检验”“区分”“验证” | 按意思选词 |
| 句与句之间缺连接词 | 按逻辑关系补上 |
| 不交代用处 | 段末或节末写这组证据说明了什么 |
| 缩写多，英文术语不括注 | 概念用中文，第一次出现时括注英文 |

## 5 参考数值（写完看一眼，不作目标）

下面的数值描述的是一篇文章的典型值在各篇之间怎样分布，不是每一段、每一句的目标。它们用来发现信息被压缩了、句子缺了主语或比较对象的情况。偏离很大时先看原因，句子按内容改，不为凑数而改。脚本加 `--style` 才输出这些数值。

**全文指标**（《心理科学进展》40 篇的中位数，括号里是四分位；不算括号里的引文）：

| 指标 | 范例 | 偏离时先看 |
|---|---|---|
| 每句汉字（全文中位数） | 48（43—52） | 主语、样本、测法和比较对象是不是被压缩掉了 |
| 每个分句汉字 | 16（14—17） | 必要的修饰是否还在 |
| “的”/百字 | 4.2（3.9—4.5） | 是不是电报体 |
| 分号/万字 | 16（11—26） | 是不是用分号串条目 |
| 冒号/万字 | 14（10—19） | 是不是“X：Y”标签句 |
| 以“此外、同时、因此、从而、然而、尽管”等开头的句子 | 11%（9%—14%） | 逻辑关系是否写在明处 |
| “其”/万字 | 28（20—41） | 指代 |
| “它/它们/他们”/万字 | 6（4—9） | 指代 |
| “进行”/万字 | 15（12—28） | 按需要用 |
| 英文术语括注/万字 | 20（12—29） | 核心术语第一次出现时是否括注 |
| 缩写/万字 | 49（25—119） | 概念是否用中文说 |
| 括号举例“(如……)”/万字 | 4（3—8） | 简短的例子 |
| “均、皆、亦”/万字 | 7（4—13） | 书面词是否过多 |

## 6 脚本

```
python scripts/check_review_prose.py 草稿.md            # 硬错误和骨架
python scripts/check_review_prose.py 草稿.md --style    # 加上文风参考数值
python scripts/check_review_prose.py 草稿.md --systematic   # 系统综述、元分析：不查项数
python scripts/check_review_prose.py 草稿.md --json
```

- **硬错误**：项数与穷尽说法、禁用的说法（标签、空过渡和目录句）、段尾防御、不同段落里说法高度重合的句子。这一栏要清零，有意的首尾对应可以留。重复句只抓措辞相近的，换了说法的重复要靠通读。
- **骨架**：每段的首句和末句，用来做第 2 节的首句连读和末句列表。
- **文风参考**（`--style`）：第 5 节的数值、长短起伏、句式与引用、论证动作。长短起伏、引用和论证动作需要至少 6 段、20 句才判断；草稿不足 1,500 汉字时，比例指标不稳定。

## 7 改稿四步

1. 找出这段要读者记住的那句话；
2. 对每个限定问：它指证据的哪种弱点？删掉后读者会不会用错结论？别处写过没有？
3. 对照原稿，检查事实、数字、引用和主张强弱有没有变；
4. 读者测试：只读这一段，同行能否说出发现了什么、证据多强、适用于谁。

## 8 范例的习惯和本规范冲突时

| 条目 | 范例的习惯 | 处理 |
|---|---|---|
| 第 19 条：写文件本身（“本节将介绍”“下文将讨论”） | 16 篇用，24 篇不用 | 节首写这一节要回答的问题；段与段之间靠上一段的结论引出下一段的问题 |
| 第 20 条：模型腔的过渡（“综上所述”“首先……最后”“值得注意的是”） | “综上”30 篇用（每万字约 1 次）；“首先……最后”30 多篇用 | “综上”只用在章末小结；“首先……最后”只在真有先后顺序或三点并列时用，如引言末段交代做法、展望；其余不用 |
| 第 6 条：假对比（“不仅……而且”“并非……而是”） | 分别有 30 篇和 26 篇用，每万字约 2 次 | 只在前后两半都提供信息，或纠正一个真实存在的误解时用 |
| 表示逻辑关系的连接词（此外、因此、然而、尽管） | 约每 8 句有 1 句以它们开头 | 照常用 |
| 自称 | 一区：we、this review；本刊以“本文”为主 | 用“本文认为”“本文提出”；“我们”少用 |
| 引用密度 | 一区每段约 2.5 篇；本刊约 1 篇 | 证据段引两三项代表研究，判断段不引；顾及参考文献总数 |
| 直接引语 | 一区常见，带页码；本刊很少 | 只用于转述对立主张和关键定义，一节一两处 |
| 要点小结、未来问题栏 | *Annual Reviews* 固定栏目；本刊没有 | 并入“总结与展望” |
| 证据分级的措辞 | 一区：strong / moderate / limited evidence | 用自然语言分级，如“较强的证据”“初步的证据” |
| 研究项数 | 系统综述里常见；本刊基本不报 | 非系统检索不报，只描述引到的研究 |
